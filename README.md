# 2017款吉利博越替换掌讯5760B车机导航接入homeassistant

>
> 把 2017 款吉利博越（加装瑞志诚协议盒 + 掌讯 5760B
安卓车机）的**车辆状态与位置**实时接入 Home Assistant。
> 车机端 Termux 只读解析协议盒串口 + 读取车机 GPS，经 MQTT 推送；HA 端自定义集成「吉利博越掌讯5760B」自动创建中文实体与地图车辆。
> **全程只读，不向车机/车辆发送任何控制指令。**
>

---

## 一、功能与特性

- **车辆状态**：发动机转速/运转、车速、方向盘转角、倒车 R 挡、四门+后备箱、空调（电源/AUTO/A/C/内外循环/双区/左右温度/风量/风向）、车机时间、协议盒型号。
- **车辆位置**：HA 地图实时车辆（device_tracker）+ 定位精度/海拔/GPS车速/方向/定位时间。
- **连接指示**：「车机导航状态」实体，ACC 开=打开、ACC 关/断联=关闭。
- **断联不丢车**：MQTT 断联时位置保留最后坐标（地图不消失），实时仪表类诚实置为不可用。
- **低延迟**：串口有数据即解析即发布，端到端约 0.25~0.5 秒。
- **低流量**：只发变化量+死区；GPS 全局每秒采样、位移≥3米才上报；停车零流量。
- **高可用**：看门狗崩溃重启 + Termux:Boot 开机自启 + 终端自愈 +（可选）Magisk ACC 守护。
- **全后台**：平时静默，`boyue status` 才输出；自启动后自动回车机桌面。
- **零 YAML**：HA 图形化添加集成，30 个中文实体自动生成，内置车标图标。

## 二、系统架构

```
瑞志诚协议盒 ──UART(/dev/ttyS1@38400,只读)──> 掌讯5760B车机(Termux,root)
                                              │ boyue_bridge.py
                                              │  ① 只读切帧解析 ② 读车机GPS
                                              │  ③ 只发变化量+死区 ④ MQTT
                                              ▼
                                         MQTT broker ──> Home Assistant
                                                          geely_boyue 集成
                                                          30中文实体+地图车辆
```

## 三、硬件与软件前提


| 项          | 要求                                                                                                                      |
|--------------|-----------------------------------------------------------------------------------------------------------------------------|
| 车机       | 掌讯 5760B（安卓），已 root（Magisk）                                                                             |
| 协议盒    | 瑞志诚 RZ，标识串 `GEELY-RZ-03-0016-B1`，串口 `/dev/ttyS1`                                                        |
| 串口共存 | 需保证读 `/dev/ttyS1` 不影响车机原车状态显示（本项目作者已解决；若你的车机冲突，见 FAQ） |
| Termux       | 主程序 + Termux:Boot（必装）+ Termux:API（可选，定位来源A）                                                 |
| HA           | 已配置 MQTT 集成并连上 broker；车机与 HA 网络互通                                                           |


> 
> 协议盒串口**不含 GPS**，位置取自车机安卓自身定位（termux-location / root dumpsys / NMEA 三来源自动选择）。

## 五、车机端安装（一键）

把 `termux/` 目录传到车机（如 `~/boyue-install/`），在 Termux 执行：

```
cd ~/boyue-install
bash install-termux.sh          # 基础安装
# 或（有Magisk、需ACC断电解冻自启）：
bash install-termux.sh --acc
```

脚本自动完成：装 python/paho-mqtt/termux-api → 部署文件 → 生成集中配置 `~/.boyue/boyue.conf` → 注入配置加载器 → 生成看门狗/开机自启/终端自愈 → 启动。

### 5.1 修改 MQTT 地址（必做）

```
nano ~/.boyue/boyue.conf
```

```
MQTT_HOST = "192.168.1.10"   # ← 改成你的 HA/broker 地址
MQTT_PORT = 1883
MQTT_USER = "mqtt"           # ← 你的 MQTT 用户名
MQTT_PASS = "改成你的密码"    # ← 你的 MQTT 密码
NODE_ID   = "boyue"          # 与 HA 集成里填的一致
```

改完 `boyue restart`。**所有 MQTT 与 GPS 参数都集中在 boyue.conf，无需改代码。**

### 5.2 修改 GPS 发送频率

同在 `~/.boyue/boyue.conf`：

```
GPS_ENABLE     = True    # 关闭位置功能改 False
GPS_POLL_S     = 1.0     # 全局采样间隔(秒)，默认每秒
GPS_DEADBAND_M = 3.0     # 位移死区(米)，移动≥3米才上报
```

- 想更省流量：`GPS_DEADBAND_M` 调大（10/20）。
- 想更平滑：保持 3。
- 改完 `boyue restart`。

### 5.3 启动与验证

```
boyue restart
boyue status     # 应显示:串口已打开[只读]、MQTT已连接、有坐标
boyue gps        # 定位三来源诊断
```

### 5.4 开机自启与 ACC 解冻

1. **打开一次 Termux:Boot**（注册开机广播）。
2. 车机设置：Termux/Termux:Boot/Termux:API 允许自启 + 电池不优化。
3. 若 ACC 断→通后仍不自启（ROM 杀后台且不发开机广播），用 `--acc` 安装 Magisk 守护，或把车机「ACC OFF 模式」改为"关机"（每次冷启动，Termux:Boot 生效）。


## 六、HA 端安装

1. 复制 `custom_components/geely_boyue/` 到 HA 配置目录 `custom_components/` 下。
2. **重启 HA**。
3. 设置→设备与服务→添加集成→搜「吉利博越掌讯5760B」→ 填节点标识（默认 boyue，与车机一致）。
4. 自动创建设备 + 30 中文实体。概览添加「地图」卡片勾选「车辆位置」。

## 八、报文解析（摘要，全文见 docs/报文解析规范.md）

帧格式：`2E <COMID> <LEN> <DATA[LEN]> <CHK>`，总长 LEN+4。校验：`CHK = (~(COMID+LEN+ΣDATA)) & 0xFF`；等价判据=含帧头整帧累加和低8位=0x2D。`0xFF` 为空闲填充需跳过；先拼连续字节流再按 LEN
切帧（粘包常态）。约90%数据走 `0x7D` 容器，`DATA[0]` 为 sub：


| sub/COMID        | 信号                 | 解码                                                    |
|------------------|------------------------|-----------------------------------------------------------|
| 7D/0A            | 转速                 | u16le/4 (rpm)                                             |
| 7D/03            | 车速                 | (u16le−156.159)/111.744 (km/h)                          |
| 7D/08            | 方向盘转角        | s16le (度,±540)                                         |
| 7D/05 & 0x24 | 车门/后备箱位图 | bit7副驾 bit6主驾 bit5右后 bit4左后 bit3后备箱 |
| 0x30             | 倒车R挡             | 出现即R，>1s无帧退出                           |
| 0x23             | 空调                 | b0位域+b4/b5温度(raw\*0.5+17)                         |
| 0x51             | 车机RTC              | DATA[3]时 DATA[4]分                                     |
| 0x7F             | 协议盒标识        | ASCII，上电/重连事件                               |
| 7D/01            | 心跳                 | 忽略，不建实体                                     |


**不提供**：P/N/D
挡（协议盒不发）、手刹、转向灯/大灯、GPS、真实总里程。

## 十、FAQ

- **Termux:API 装不上（应用未安装）**：签名不匹配，正常。跳过，程序自动用 root dumpsys/NMEA 定位。
- **开机/ACC 后不自启**：打开过 Termux:Boot 吗？ROM 自启/电池白名单加了吗？仍不行用 `--acc` 或改 ACC OFF 为关机。
- **桥接 rc=127 循环**：python 未装或环境残缺，重跑 install-termux.sh（已硬编码环境）。
- **位置不更新**：车机自身没开导航时 dumpsys 缓存旧；保持导航开启或装 Termux:API。
- **读串口影响原车显示**：本项目作者已解决共存；若你的车机冲突，可试 socat 分流或停用原厂 canbox（会失去原车弹窗）。
- **HA 图标不显示车图**：HA 2026.3+ 自动读本地 brand；旧版自定义集成可能显示默认图标，正常。

## 十一、已知边界

- 车速标定区间 5~40km/h，高速外推，勿做超速告警；不做里程积分。
- P/N/D 不可区分，仅 R 可判。
- 地库/隧道无 GPS 时退化为网络定位或保持最后位置。
